## 🚀 Flagship Project — ZS_Live

<div align="center">
  <img src="https://img.shields.io/badge/License-Source%20Available-00E5FF?style=for-the-badge" />
  <img src="https://img.shields.io/badge/Language-JavaScript%20%2F%20C%23-00E5FF?style=for-the-badge" />
  <img src="https://img.shields.io/badge/Platform-Windows%20%2F%20Linux-00E5FF?style=for-the-badge" />
</div>

**ZS_Live** is a self-hosted cloud-gaming & real-time broadcast platform:

- 🎮 **GPU Instance Orchestration** — NVENC hardware encoding with GPU-weight admission control (up to 6× 4K@30 on a single RTX 4090)
- 📡 **Real-time Streaming** — RTSP / WebRTC ingest & playback via MediaMTX, sub-second latency
- 🔐 **License System** — RSA-signed tokens gating instance count & expiry across 3 customer tiers (trial / app-license / source)
- 🖥 **Cross-platform Admin** — reactive web console + native WinForms signing tool
- 🧩 **UE Integration** — custom Unreal Engine plugin for in-engine capture & control channel

> 🔒 The source-available edition and deployment packages are on the public repo; the full private mirror (incl. signing keys & build artifacts) lives in the private repo.
